ENTROPIA

Czas jest entropią. Tyknięcia są dyskretne. Czas potrafi „czkać”.

Kosmologiczny model łączący mechanikę kwantową układów otwartych (równanie Lindblada dla kubitu w kąpieli termicznej) z relacyjną koncepcją czasu: zegar kosmiczny nie mierzy upływu zewnętrznego czasu, lecz kumuluje produkowaną entropię.

Siedem cech

Kubit w kąpieli termicznej Lindblada — z jednego mechanizmu wynika siedem obserwowalnych zjawisk.

01

Entropia S(ρ)

Monotoniczny wzrost dzięki mapie unitalnej (tw. Ando–Lindblada); produkcja entropii σ ≥ 0 (tw. Spohna).

0 → ln 2
02

ΔS_n na tyknięcie

A produkuje entropię szybciej niż B — temperatura ustawia tempo, nie cel. s ∝ T³.

27× (T_A = 3·T_B)
03

Skumulowany czas

Czas kosmologiczny jest sumą przyrostów entropii — nie jest postulatem, lecz wynikiem.

T(n) = S(n), κ = 1
04

Dyskretne tyknięcia

Czas kwantowany w „bitach” δs — jawne schodki, nie ciągły przepływ.

k_n ~ Poisson(ΔS_n/δs)
05

„Czkanie czasu”

Przy niskiej produkcji entropii Δt_n → 0 — długie zamrożenia, potem skok.

151/160 zer w ogonie (B)
06

T_A/T_B

Czas w gorącym otoczeniu płynie szybciej; w granicy ciągłej t→0 stosunek jest dokładny.

→ 27 (ciągła granica)
07

Dekoherencja i Bloch

Czystość Tr(ρ²) i długość wektora Blocha |r| zanikają wraz z termalizacją.

Tr(ρ²): 1→0.5 · |r|: 1→0
Aparat matematyczny

Kluczowe równania

Mikrofizyka: równanie Lindblada dla kubitu w kąpieli. Makrofizyka: zegar kosmiczny zbudowany z przyrostów entropii.

Równanie Lindblada

dρ/dt = −i[H,ρ] + Σ_k ( L_k ρ L_k†
         − ½{L_k†L_k, ρ} )

ρ_n = e^(ℒτ) ρ_(n−1)   (mikro-tyknięcie τ)

Produkcja entropii (tw. Spohna)

σ = −d/dt S(ρ‖ρ_eq) ≥ 0

ΔS_n = S(ρ_n) − S(ρ_(n−1))
T(n) = Σ_k Δt_k,   Δt_n = κ·ΔS_n

Kompresja czasu 27×

s ∝ T³   (entropia właściwa promieniowania)
γ_A/γ_B = (T_A/T_B)³

T_A = 3·T_B  ⟹  γ_A = 27·γ_B

Czkanie czasu (kwantyzacja)

δs — kwant entropii („bit")
k_n ~ Poisson(ΔS_n/δs)
Δt_n = k_n · δs

ΔS_n mały ⟹ P(k_n=0) wysokie ⟹ Δt_n=0

Kąpiel skończonej temperatury (R1)

η = e^(−βΩ)
a = 2γ/(1+η)   (emisja)
b = 2γη/(1+η)  (absorpcja)

S(∞) = H(1/(1+η)) < ln 2

Falsyfikowalność

Predykcje a dane obserwacyjne

Model jest fenomenologiczną zabawką, ale zbudowaną na prawdziwym prawie: s ∝ T³. Poniżej kluczowe testy z PREDYKCJE.md.

✅
P1 — s ∝ T³: entropia promieniowania skaluje się jak T³
T_ν/T_γ = (4/11)^(1/3) = 0.7138, N_eff = 2.99 ± 0.17 (Planck 2018) — zgodność ilościowa. Najsilniejszy test: mechanizm modelu to mechanizm realnej kosmologii.
✅
P2 — Strzałka czasu = wzrost entropii
S(ρ) rośnie monotonicznie 0 → ln2 (tw. Ando–Lindblada) — kierunek zgadza się z drugą zasadą termodynamiki.
🟡
P3 — „Zegar entropii”: wiek kosmiczny ∝ wyprodukowana entropia
Egan & Lineweaver 2010: S_obs = 3.1×10¹⁰⁴ k_B, wskazówka zegara ≈ 1.2×10⁻¹⁸ — jakościowa zgodność, Wszechświat daleki od równowagi.
✅
P7 — Subradiancja: eksperymentalnie zmierzona w zimnych atomach
PRL 116, 083601; PRL 128, 203601 — analogia do „ciemnej" entropii sektorów w modelu (R2 |10⟩: 50% entropii ukryta).
❓
Test rozstrzygający T1 vs T2 — protokół R23
Zimne atomy ⁸⁷Rb / ¹³³Cs / wnęka optyczna — pomiar informacji wzajemnej I(A:B) w fazie ciemnej rozstrzyga, czy zegar staje po wygaśnięciu fluorescencji. Pełny arkusz: EKSPERYMENT.md.
